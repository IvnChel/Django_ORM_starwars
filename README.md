# 🌌 Имперская база данных

Веб-приложение на Django для хранения и отображения информации о персонажах и космических кораблях вселенной "Звёздных войн".

## 🚀 Установка и запуск

### 1. Клонирование и настройка окружения
```bash
# Создайте папку проекта и перейдите в нее
mkdir starwars_project
cd starwars_project

# Создайте виртуальное окружение и активируйте его
python -m venv venv

# Для Windows:
venv\Scripts\activate

# Для Mac/Linux:
source venv/bin/activate
```

### 2. Установка Django и запуск проекта
```bash
# Установите Django
pip install django

# Скопируйте файлы проекта в папку:
# - Все файлы из папки imperial_database (кроме venv)
# - Убедитесь что есть manage.py в корне

# Примените миграции для создания базы данных
python manage.py migrate

# Создайте администратора для доступа к админ-панели
python manage.py createsuperuser
# Введите имя пользователя (например: admin), email (можно пропустить) и пароль
```

### 3. Импорт данных из SWAPI
```bash
# Загрузите всех персонажей и корабли из Star Wars API
python database/import_from_swapi.py

# На вопрос "Очистить существующие данные?" ответьте 'n' (нет)
# Скрипт автоматически загрузит 82 персонажа и 36 кораблей
```

### 4. Запуск сервера
```bash
# Запустите сервер разработки
python manage.py runserver

# Откройте браузер и перейдите по адресу:
# http://127.0.0.1:8000/ - главная страница приложения
# http://127.0.0.1:8000/admin/ - админ-панель (используйте логин/пароль от createsuperuser)
```

## 📱 Использование приложения

### 🌐 Веб-сайт
1. **Главная страница** (`/`) - список всех персонажей "Звёздных войн"
2. **Страница персонажа** - кликните на любого персонажа для просмотра детальной информации
3. **Страница корабля** - с главной страницы персонажа перейдите к его кораблям

### 👑 Админ-панель
- Доступ: `http://127.0.0.1:8000/admin/`
- Что можно делать:
  - Просматривать всех персонажей и корабли
  - Добавлять новые записи
  - Редактировать существующие данные
  - Управлять связями между персонажами и кораблями
  - Искать и фильтровать записи

## 🛠️ Технологии
- **Backend**: Django 5.2 + Python
- **База данных**: SQLite
- **Фронтенд**: HTML, CSS, Django Templates
- **Данные**: Star Wars API (SWAPI)

## 🔧 Если что-то не работает
1. **Проверьте что виртуальное окружение активировано** - в начале строки терминала должно быть `(venv)`
2. **Убедитесь что находитесь в папке с manage.py**
3. **Проверьте что Django установлен**: `python -c "import django; print(django.__version__)"`
4. **Если импорт не работает** - проверьте подключение к интернету

# 🌌 Имперская база данных

Веб-приложение на Django для хранения и отображения информации о персонажах и космических кораблях вселенной "Звёздные войны".

## 🎯 Возможности проекта

- 📋 **Полный каталог** всех 82 персонажей "Звёздных войн"
- 🚀 **Информация о кораблях** с техническими характеристиками
- 🔗 **Автоматические связи** между персонажами и их кораблями
- 🌐 **Загрузка данных** из открытого API SWAPI
- 👑 **Административная панель** для управления данными
- 📱 **Адаптивный дизайн** с тематическим оформлением

## 🛠️ Технологический стек

- **Backend**: Django 5.2 + Python 3.11
- **База данных**: SQLite (разработка) / PostgreSQL (продакшн)
- **Frontend**: HTML5, CSS3, Django Template Language
- **API**: SWAPI (Star Wars API) для импорта данных
- **Стилизация**: CSS Grid, Flexbox, кастомная стилизация
